# טורבו — מרוץ אונליין לשני שחקנים

הפרויקט שומר על משחק הנהיגה המקורי ומוסיף חדר פרטי עם קוד, עד שני שחקנים, ושידור מצב הנהג בזמן אמת באמצעות WebSocket.

## להריץ במחשב

נדרש Node.js 20 ומעלה.

```bash
npm install
npm start
```

פתחו `http://localhost:3000`. כדי לבדוק שני שחקנים באותו מחשב, פתחו חלון רגיל וחלון פרטי, אבל כדי לבדוק חיבור בין טלפונים צריך לפרסם את השרת או להריץ אותו על רשת נגישה.

## פרסום באינטרנט (Render)

המשחק משתמש ב-WebSocket קבוע, לכן יש לפרסם את השרת כ-Web Service ולא רק כאתר סטטי. Render הוא אפשרות נוחה.

1. צרו מאגר GitHub חדש והעלו אליו את כל הקבצים שבתיקייה הזו (`server.js`, `package.json`, `public/index.html`, `README.md`).
2. ב-Render בחרו **New → Web Service** וחברו את מאגר GitHub.
3. הגדירו:
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Runtime:** Node
4. פרסמו את השירות ופתחו את כתובת `https://....onrender.com` שהתקבלה.
5. בדקו בשני מכשירים: שחקן אחד יוצר חדר, שולח את הקוד לשחקן השני, וכששניהם בחדר המארח לוחץ על התחלת המרוץ.

בדקו את מגבלות התוכנית החינמית של ספק האירוח לפני הפרסום; תוכניות חינמיות עשויות להירדם, להיות מוגבלות או להשתנות. אין צורך להגדיר כתובת WebSocket בנפרד: הדף משתמש אוטומטית ב-`wss://` באתר HTTPS.

## הערות חשובות על גרסה זו

- החדרים נשמרים בזיכרון השרת. אם השירות מופעל מחדש, החדרים נסגרים.
- עד שני שחקנים בחדר; אין חשבונות משתמשים או שמירת תוצאות קבועה.
- כל לקוח מריץ מקומית את תנועת המכונית והמסלול, והשרת מעביר את מיקום/ניקוד היריב כדי להציג אותו בזמן אמת. זהו אבטיפוס למשחק חברים, לא מערכת תחרותית חסינת רמאות. מכיוון שהמכשירים מייצרים מכשולים אקראיים בנפרד, המכשולים אינם מסונכרנים בדיוק בין השחקנים.
